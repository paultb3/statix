# Statix

**DataViz Excel** es una aplicación web ligera que permite:

- 📥 Importar datos directamente desde archivos Excel (.xlsx)  
- 📊 Calcular y mostrar tablas de frecuencia (absolutas y relativas)  
- 📈 Generar gráficos dinámicos (histogramas, barras y sectores)  
- 📱 Ofrecer una interfaz responsiva que funciona en escritorio y móvil

## ⚙️ Características

- **Carga de Excel**: Selección de archivo `.xlsx` sin configuraciones previas.  
- **Tablas de Frecuencia**: Cálculo automático de frecuencias absolutas y relativas.  
- **Gráficos Dinámicos**:  
  - Histograma  
  - Gráfico de barras  
  - Gráfico de sectores (pie chart)  
- **Responsive**: Adaptación automática a distintos tamaños de pantalla.  
- **Sin dependencias de backend**: 100 % JavaScript, se ejecuta en el navegador.
